2026-09-06，Windows x64。

- 首次打开显示欢迎界面，用户主动选择本地模式或配置大模型；选择会持久保存。
- 本地模式默认每项 30 分钟，不需要密钥。配置未保存成功时不会跳过欢迎界面。

- 48 项单元测试和 36 项界面回归通过，新增首次选择、保存失败、升级兼容和窗口显示时序验证。
- 真实独立程序与便携版首次启动验收通过：欢迎界面可见、本地模式无需密钥、选择保存后重启不再询问。

安装 0.2.1 前请从托盘退出旧版，再运行新版安装包。若此前从未保存过模式设置，升级后会显示欢迎界面；已经保存过设置的用户可点击右上角模式按钮调整。

# 0.2.0 发布说明

2026-09-06，Windows x64。

## 使用变化

- 默认本地模式，无需 API Key，生成和手动新增任务的耗时默认 30 分钟。
- 软件内可选择启用大模型，并填写接口地址、模型和 API Key；模型仅用于估算耗时。
- 模型失败自动回退到 30 分钟并明确提示，已有任务耗时不受模式切换影响。
- API Key 由 Windows 系统加密保存。关闭 AI 后不再请求模型；删除全部本地数据同时清除密钥。
- 首次启动使用空白任务列表。关闭窗口隐藏到托盘，可重新打开；支持单实例。
- 提供安装版、便携版与 SHA256SUMS.txt，无需 Node.js、npm 或独立 AI 网关。

## 本机验证记录

- 类型检查和静态检查通过。
- 43 项单元测试通过，覆盖本地默认耗时、禁止网络请求、模型有效/无效返回、超时、密钥保存和设置恢复、打包配置。
- 27 项浏览器回归通过，覆盖 1440/1080/390 像素宽度下的原有流程与模式切换。
- 真实 Electron 验收通过：SQLite、IPC、30 分钟任务、Windows 密钥加密、重启恢复、托盘、数据清除。
- NSIS 实际静默安装、安装后运行及卸载通过；安装使用临时目录，并拒绝覆盖已有安装。
- 便携版自解压、启动、真实 IPC 和默认 30 分钟任务生成通过。
- 已确认打包内容不含 .env、用户 SQLite 数据库或 AI 设置文件。

没有使用真实付费密钥调用在线模型；模型协议与响应处理使用测试替身验证。未提供代码签名证书，当前 exe 未签名。本次交付为本地发布文件，尚未上传公共下载站点。

```powershell

npm run dist:win
npm run test:desktop
```
